# 폰트 폴더

ullim Design System 지정 본문 폰트 **Arita Buri**를 여기에 넣어 주세요.

```
public/fonts/AritaBuri.ttf
```

- 아리따 부리는 아모레퍼시픽 [아리따 글꼴 페이지](https://www.apgroup.com/int/ko/about-us/visual-identity/arita-typeface.html)에서 내려받을 수 있습니다 (라이선스 동의 필요).
- 파일이 없는 동안에는 결이 비슷한 **고운바탕(Gowun Batang)** 으로 자동 폴백됩니다.
- 파일명이 다르면 `app/globals.css`의 `@font-face` 선언에서 경로를 맞춰 주세요.
